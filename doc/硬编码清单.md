## 十一、风险矩阵与整改优先级

| 优先级 | 类别 | 典型项 | 理由 |
|---|---|---|---|
| **P0** | 演示/种子安全 | `pass123` ×3、公开 `/seed`、`SECRET_KEY` 占位 | 公开服务=直接可入侵 |
| **P0** | 模型链路 | `agents_tools.py:64` 默认 `model="openrouter"`、config 默认空串依赖 env | 漏配即模型调用失败/异常模型 id |
| **P1** | 指标失真 | `_record_metrics` 的 `latency=0/cost=0` | 监控面板数据不可信 |
| **P1** | Trace 版本 | `"M4-agents"` ×4 + `"M2-v1"` 并存 | 审计版本错乱 |
| **P2** | 阈值外部化 | `MAX_HISTORY`/`MAX_OBS_LEN`/`WINDOW_MINUTES`/`top_k`/`temperature`/`max_tokens` | 调参需改代码 |
| **P2** | 重复维护 | `_TOOL_ROLES` vs 注册表 roles | 权限漂移 |
| **P3** | 演示数据标注 | `user_dir` 假用户、`grant` 内存态、`DEFAULT_KB` | 代码可读性与边界清晰 |

## 十二、整改建议（按文件）

1. **`app/skills/registry.py`**：作为"工具→角色"的唯一事实源；`app/agents_tools.py:142-148` 改为从 registry 读取（删 `_TOOL_ROLES`）。
2. **`app/config.py`**：新增 `LLM_TEMPERATURE`、`LLM_MAX_TOKENS_CLASSIFY/REWRITE`、`CTX_MAX_HISTORY`、`CTX_MAX_OBS_LEN`、`CTX_MIN_TRUNCATE`、`DEDUP_WINDOW_MINUTES`、`SESSION_TTL_HOURS` 等；`top_k` 统一引用 `settings.vector_top_k`。
3. **`app/agents_tools.py:64`**：`model = c.get("model", settings.agent_model)`。
4. **`app/orchestrator.py:339-341`**：从工具调用/token 用量累计真实 `latency` 与 `cost`（或标 TODO 明确忽略）。
5. **`app/agents_runner.py` / `agents_tools.py` / `agents_trace.py` / `orchestrator.py`**：`prompt_version` 收敛为单一常量（如 `app/agents_runner.py` 导出 `PROMPT_VERSION`，全项目引用）。
6. **`app/api/auth.py`**：生产删除自动播种或改 `APP_ENV!=production` 才生效；种子密码改随机生成/环境变量。
7. **`app/tracelog.py:52`**：日志目录支持 `LOG_DIR` 环境变量。
8. **统一整理**：把提示词（classifier / agents_defs / context_assembler 模板）抽到 `app/prompts/` 或配置目录，便于版本管理与替换。
