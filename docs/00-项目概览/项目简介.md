# 项目简介

> 状态：现行 · 最后校验：2026-08-18 · 校验方式：符号级 + 行为实测
> 本页回答「这是什么项目、怎么分层、演进了哪些里程碑」。架构大图与 8 大能力图见根 [README.md](../../README.md)。

## 1. 一句话定位

一个运行在单机上的**企业 IT 工单智能处理系统**，完整展示「企业级 Agent Harness」的工程能力：不是演示「AI 多聪明」，而是演示「**AI 如何被可靠、可控、可审计地接进企业业务**」。系统把大模型当作「判断层」，把执行权交给确定性的流程、权限与审批。

**三个关键词**（贯穿全场）：
- **可靠**（Reliable）：状态机约束、幂等、预算、停止条件——不跑飞；
- **可控**（Controlled）：IAM 最小权限、工具白名单、HITL 审批——不越权；
- **可审计**（Auditable）：Trace 全链路、监控指标——出错能查。

## 2. 架构核心：自研治理层 + OpenAI Agents SDK

| 层 | 归属 | 内容 |
|---|---|---|
| 治理层（Harness，**自研**） | 本项目掌控 | 状态机、预算、守卫、审批持久化、Trace、指标、工具白名单/脱敏/幂等 |
| 智能层（**OpenAI Agents SDK**） | 官方成熟能力 | `Agent + Runner` 工具循环、多 Agent handoff、原生 interruptions（HITL） |

一句话：**LLM 循环用官方 SDK，企业治理保留自研**——既拿到 SDK 的多 Agent 编排能力，又守住确定性流程。模型侧 OpenRouter（主）⇄ Ollama（兜底）⇄ 离线 reader（保底），全部走 OpenAI Chat Completions 兼容协议（`app/agents_provider.py:RouterProvider`）。

## 3. 角色与工具面

| 角色 | 说明 | 可见工具 |
|---|---|---|
| `employee` | 普通员工，建单/查询 | 只读：`search_kb` `search_kb_direct` `query_user_dir` + MCP 只读（cmdb/github 低风险） |
| `operator` | 运维，可执行变更 | 全部（含高风险变更工具） |
| `admin` | 管理员，可执行变更/审批 | 全部 |

工具按角色过滤（`app/skills/registry.py:tools_for_role` + `app/agents_tools.py:build_agent_tools`），RBAC 在工具层真正生效。工具面 = **MPC-Skill 自研 5 工具** + **MCP 外部工具面 8 映射工具**（详见 [01-企业级Agent-Harness.md](../01-核心功能/01-企业级Agent-Harness.md) 与 [03-MCP工具集成.md](../01-核心功能/03-MCP工具集成.md)）。

## 4. 技术栈

| 层 | 选型 | 为什么 |
|---|---|---|
| 后端 | Python + FastAPI | 轻量、结构化、面试可逐行讲解 |
| Workflow | 自研状态机 | 不用 LangGraph，快照/HITL 原理可控可讲 |
| LLM 编排 | OpenAI Agents SDK（`openai-agents==0.20.0`） | `agent+Runner` 原生工具循环/多 Agent handoff；`RouterProvider` 统一 Chat Completions |
| 模型 | OpenRouter 主 ⇄ Ollama 兜底 ⇄ 离线 reader | 三级降级，离线可演示 |
| RAG | LanceDB 向量 + SQLite FTS5 + rerank | 双路召回 + RRF 融合 + 精排（见 [02-RAG知识库.md](../01-核心功能/02-RAG知识库.md)） |
| MCP | `mcp==2.0.0`（stdio + streamable_http） | 外部工具/数据源标准接入，治理不外包（见 [03-MCP工具集成.md](../01-核心功能/03-MCP工具集成.md)） |
| 存储 | SQLite（WAL）+ 文件系统 | 单机、0 成本、状态外部化 |
| 前端 | Next.js 14（App Router，客户端 SPA） | 贴近真实企业栈，与 FastAPI 解耦 |
| 部署 | Docker Compose + Nginx（单机） | 阿里云 Ubuntu 零成本上线 |

## 6. 演示路径（面试 10 分钟版）

1. 建一张「开通 DB 只读账号」高风险工单 → 快速落单 + 流式 stage 进度 + 风险自动分级；
2. 看 Agent LOOP：上下文装配（选/压/截）、多 Agent handoff、工具白名单、脱敏；
3. 触发 HITL：`awaiting_approval` → 审批台批准 → 恢复执行 → 回合收敛 → 客户确认 → `done`；
4. 打开 Trace 时间线：模型版本/提示词版本/工具调用/状态转移一屏可见；
5. 打开 `/metrics`：成功率、正确失败率、延迟、成本、人工接管率；
6. 亮出 MCP：CmdbAgent 查询 CMDB（`GET /api/mcp/servers` 现场展示白名单与 risk 映射）；
7. 收尾：讲「切 Ollama / 走 SSO / 上 K8s」——展示可演进性。
