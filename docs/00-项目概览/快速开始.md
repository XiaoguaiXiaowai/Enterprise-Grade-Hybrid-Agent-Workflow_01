# 快速开始

> 状态：现行 · 最后校验：2026-08-18 · 校验方式：符号级 + 行为实测
> 目标：5 分钟内本地跑起「后端 + 前端」并完成一次冒烟。完整部署见 [03-部署运维/部署手册.md](../03-部署运维/部署手册.md)。

## 1. 环境要求

- Python 3.10+（建议 3.11/3.12）、Node.js 18+
- 可选：本地 Ollama（`http://127.0.0.1:11434/v1`，兜底 LLM / embedding / rerank）；不装也能跑（离线 reader 降级）

## 2. 后端（FastAPI）

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt          # 版本已锁定
cp .env.example .env                     # 按需填写 OPENROUTER_API_KEY（不填则直落 Ollama / reader）
uvicorn app.main:app --reload --port 8000
```

验证：

```bash
curl -s localhost:8000/health                            # {"status":"ok",...}
curl -s localhost:8000/api/auth/seed-info                # 查看种子账户与密码（seed 后）
```

**演示账户**：`admin` / `operator` / `employee`。密码**不再硬编码**：优先取环境变量 `SEED_USER_PASSWORD`，缺省随机生成；运行 `scripts/seed_demo.py` 后默认密码为 `demo-pass-2026`（可用 `SEED_USER_PASSWORD` 覆盖）。`APP_ENV=production` 时禁用演示 seed，用 `scripts/init_prod.py` 建生产账户。

## 3. 造演示数据（可选但推荐）

```bash
. .venv/bin/activate
python scripts/seed_demo.py     # 幂等：账密、知识库、示例工单
python scripts/index_kb.py      # 向量索引（需 embedding 可用，失败可暂不执行，检索走关键词）
```

## 4. 前端（Next.js）

```bash
cd web
npm install
cp .env.example .env.local      # NEXT_PUBLIC_API_URL=http://localhost:8000
npm run dev                     # http://localhost:3000
```

页面：`/login` 登录 → `/tickets` 工单台（建单/列表/SSE 兼容+WS 实时流）→ `/approve` 审批台 → `/traces/[id]` 回放 → `/metrics` 指标 → `/kb` 知识库 → `/mcp` MCP 状态。

## 5. 一键冒烟（推荐顺序）

| 命令 | 验证什么 | 依赖 |
|---|---|---|
| `APP_DB_PATH=/tmp/smoke.db python scripts/run_all_tests.py` | 全分支（离线确定性组，全 PASS 为绿） | 无 |
| `python scripts/smoke_mcp_core.py` | MCP 治理链路（26 断言） | 无（本地 stdio 子进程） |
| `python scripts/smoke_m2.py` | 低风险 + 高风险 HITL + Trace + 指标全链路 | 弱（无 key 走 reader） |
| `python scripts/rbac_smoke.py` | RBAC 角色可见范围/删除权限 | 无 |
| `python scripts/smoke_agents.py` | SDK 真实链路（handoff + HITL + 跨进程恢复） | OpenRouter key + 网络 |
| `python scripts/smoke_mcp.py` | MCP 真实链路端到端 | OpenRouter key + 网络 |

> ⚠️ `scripts/smoke.py`（M1 期）的终态断言仍是旧口径（直接 `done`），与当前「回合收敛 → `pending_confirm` → 确认 → `done`」流程冲突，**当前会 FAIL**；请使用上表脚本。

## 6. 常见问题

- **登录 401**：先跑 `scripts/seed_demo.py` 或检查 `APP_ENV`（production 下演示账户不存在）。
- **模型 400/超时**：推理类模型需调大 `LLM_MAX_TOKENS_CLASSIFY/REWRITE`（见 [配置清单.md](../03-部署运维/配置清单.md) 陷阱 3）；主用失败会自动降级 Ollama / reader。
- **MCP server 拉起失败**：`python scripts/diag_mcp_stdio.py` 诊断 stdio 拉起真因。
- **想彻底离线**：`.env` 中不配 `OPENROUTER_API_KEY`，且 `OLLAMA_BASE_URL` 指向不可达地址 → Agent 链路自动走离线 reader（可演示）。
