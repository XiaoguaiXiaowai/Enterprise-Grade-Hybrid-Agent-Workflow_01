## 文档维护铁律

1. **单一权威源**：每个主题只有一份现行文档；配置键只在 [03-部署运维/配置清单.md](03-部署运维/配置清单.md) 定义一次。
2. **代码与文档同 PR**：新增/改名/删除函数、模块、配置键时，必须同步更新对应文档与 [能力-代码映射表](01-核心功能/06-能力-代码映射表.md)。
3. **机器校验**：`python3 scripts/check_docs.py` 必须通过（已接入 GitHub Actions `deploy.yml` 的 `docs-check` job，失败阻断部署）。
4. **元信息头**：每篇现行文档头部含「状态 / 最后校验 / 校验方式」块，发布前刷新。
5. **归档隔离**：历史内容一律进 `99-归档/`，不在现行文档中保留旧实现描述。
