## 0. 配置优先级总规则

- **LLM（chat）**：`主用(OpenRouter) → Ollama 兜底 → 离线 reader`；调用失败自动降级（详见 02-架构设计/模型路由与降级.md）。
- **embedding**：`主用(OpenRouter) → Ollama 兜底`；主用未配置或失败时切换兜底，两路都不可用则向量检索降级为纯关键词。
- **提供方选择**：未配置 `OPENROUTER_API_KEY` 时，Agent 链路直接路由 Ollama（离线可跑）。

## 13. 已知陷阱

1. **空值覆盖默认**：`.env.example` 中 `EMBEDDING_MODEL=`（空串）在 `cp .env.example .env` 后会让 `os.getenv` 返回空串而非代码默认值 → 主用 embedding 被跳过，直落 Ollama；同时会使 `scripts/verify_model_config.py` 与 `tests/test_model_config.py` 的默认值断言失败。行为归属：配置了空值就是空值。
2. **分类模型的实际消费方**：`classifier.py` 不直接读 `CLASSIFIER_MODEL`，而是经 `RELEVANCE_MODEL → CLASSIFIER_MODEL`、`REWRITE_MODEL → CLASSIFIER_MODEL` 的 `_first_nonempty` 链（`app/config.py`）。
3. **推理类模型需调大 `LLM_MAX_TOKENS_*`**：`max_tokens` 是含推理 token 的总输出预算，主用推理模型（如 liquid/*）时 512 可能被思考阶段耗尽。
4. **无 key + Ollama 失败 = 无三层兜底**：SDK 路径只有 `provider=openrouter` 的异常才触发 Ollama 重建；未配 `OPENROUTER_API_KEY` 直落 `provider=ollama` 后若 Ollama 也失败，`agents_runner.run_sdk` 抛 `RuntimeError`（非 `SdkUnavailable`），orchestrator 只捕获 `SdkUnavailable`，异常直接上抛置 `failed`。想完整演示三级降级，请配 key 或保证 Ollama 可用。
