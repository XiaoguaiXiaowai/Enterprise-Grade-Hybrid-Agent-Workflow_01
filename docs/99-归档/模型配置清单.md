# 模型配置清单
<!-- check_docs-ignore-token: MODEL_PROVIDER, MODEL_NAME, OLLAMA_MODEL_NAME, OPENAI_API_KEY, OPENAI_BASE_URL -->

本文档为全项目 LLM / embedding 配置的唯一权威来源。所有模型参数均通过环境变量注入，
无任何硬编码模型名或服务器地址。

## 配置优先级总规则

- **LLM（chat）**：`主用(OpenRouter) → Ollama 兜底 → 离线 reader`；调用失败自动降级。
- **embedding**：`主用(OpenRouter) → Ollama 兜底`；主用未配置或失败时切换兜底。
- **提供方选择**：未配置 `OPENROUTER_API_KEY` 时，Agent 链路直接落 Ollama，保证离线可跑。

## 键清单

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| `OPENROUTER_API_KEY` | *(空)* | OpenRouter 主用密钥 |
| `OPENROUTER_BASE_URL` | `https://openrouter.ai/api/v1` | OpenRouter 主用端点 |
| `OLLAMA_BASE_URL` | `http://127.0.0.1:11434/v1` | Ollama 通用服务器地址（LLM 兜底 / embedding 兜底共用） |

## 已移除的旧键（彻底重命名）

以下键已删除，如环境/文档中残留请迁移至新键：

- `MODEL_PROVIDER` → 删除（提供方由 `OPENROUTER_API_KEY` 是否配置 + 熔断决定）
- `MODEL_NAME` → `AGENT_MODEL` / 各场景模型键
- `OLLAMA_MODEL_NAME` → `AGENT_FALLBACK_MODEL`
- `OPENAI_API_KEY` / `OPENAI_BASE_URL` → 删除（兼容网关不再使用）

## 熔断路径

1. **Agent 链路**：`OpenRouter` 调用异常 → 用 `AGENT_FALLBACK_MODEL` + `OLLAMA_BASE_URL` 重建 Agent 组重跑；均不可用抛 `SdkUnavailable` → 降级传统 `LLMGateway`（其内部再走 OpenRouter→Ollama→reader）。
2. **传统网关 / 分类**：`主用(OpenRouter) → Ollama 兜底 → reader / 规则`。
3. **embedding**：`OpenRouter 主用 → Ollama 兜底`；两者均失败由上层 `search/index` 降级为空召回，最终回退关键词检索。
